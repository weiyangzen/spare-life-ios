# spare-life-ios-preview-host

Minimal iOS host app for running the Spare Life SwiftUI surfaces on real iPhone and iPad devices.

Open `SpareLifePreviewHost.xcodeproj` in Xcode, pick your signing team, then run on:

- iPhone 15 Pro
- iPad Air

The host compiles the existing sources from `../spare-life-ios-app/` so UI fixes happen in one place.
